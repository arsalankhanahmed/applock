# AuditX Frontend

Next.js 14 (App Router) + TypeScript + Tailwind CSS command center: leakage metrics, discrepancy tracking matrix
with AI fix previews, and the Chat-with-your-Ledger console.

```bash
cp .env.example .env.local      # NEXT_PUBLIC_API_URL=http://localhost:8000
npm install
npm run dev                     # http://localhost:3000/dashboard
```

Full deployment manual: [`../docs/AUDITX_MANUAL.md`](../docs/AUDITX_MANUAL.md)
